Notebooks
=========

Ordre conseillé :

1. 01_generer_csv.ipynb : génère les CSV de métriques depuis data/MainTable.csv.
2. 01b_recap_donnees.ipynb : contrôle rapide des données produites.
3. 02_acp_analyse.ipynb : agrège les métriques et lance l’ACP.
4. 02_kmeans_analyse.ipynb : agrège les métriques et lance le K-means.

Dépendances : pandas, numpy, scikit-learn, matplotlib, jupyter.
